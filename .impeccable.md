# Portfolio — Vishal Maurya

## Design Context

### Users
Hiring managers, design leads, and recruiters at **Indian product companies** — quick-commerce, food-ordering, shopping, consumer-ecom (Swiggy, Zepto, Blinkit, Zomato, Flipkart, Myntra, Meesho, Nykaa, CRED-adjacent tier). They land here from LinkedIn, Read.cv, referrals, or a cold outreach email. They spend 60–90 seconds deciding whether to schedule a call. Mobile matters — these teams ship mobile-native products and will instinctively check how the portfolio holds up there.

### Brand Personality
Three words: **quiet, unhurried, precise.** Voice: direct, specific, no marketing varnish. Emotional goal: reader thinks "this reads like a person who ships, writes clearly, and isn't performing."

Anti-tone: motivational-poster copy, breathless "crafting delightful human-centric experiences" language, template bios, performative minimalism.

### Aesthetic Direction
**Text-first / reading-first / reference-family minimal.** The site reads like a document: a single column, left-aligned, generous whitespace, one clean sans-serif throughout. No serif display treatments. No italics for emphasis. No expressive hero. No card grids on index pages. Content is presented as lists and paragraphs.

Reference-family cues (the look-and-feel bucket the site belongs to — we do NOT literally replicate any single reference): simple text-list project indexes, single-column body pages, cool-neutral monochrome, sparse typography hierarchy, tiny label meta, minimal chrome.

**Light mode only** (v1). Cool neutral, no warm tint.

### Design Principles
1. **Words first, chrome second.** If it can be a paragraph or a line of text, it is. Graphic containers, borders, and decoration only where they're doing real work.
2. **One font, honest hierarchy.** Size, weight, and muted color carry the hierarchy — not multiple families or italics.
3. **Status over hype.** Every project carries a status label (Live / Shipped / Concept) and a year. No "selected work" peacocking.
4. **Motion is for state, not for show.** No page-load animations. Hover states and scroll-spy only. Respect reduced-motion.
5. **Mobile is not a shrunken desktop.** Stacks cleanly, no amputation.

### Typography
**Geist** (variable, via `next/font/google`) is the single family — regular body, medium for headings, no italics in the design system. Mono variant available for tabular data but rarely used.

Deliberately NOT: Inter, DM Sans, Plus Jakarta, Source Serif, Instrument Serif, Instrument Sans, or any of the impeccable "reflex font" list. Geist is distinctive enough without being a reflex pick.

### Color
Cool-neutral monochrome, very slight cool tint (chroma ~0.003-0.005). Defined in `app/globals.css`:
- `--color-bg: oklch(0.985 0.002 260)` — near-white, faintly cool
- `--color-ink: oklch(0.15 0.005 260)` — cool near-black (not pure)
- `--color-ink-soft`, `--color-muted`, `--color-line`, `--color-line-soft` — all cool-tinted neutrals

No accent color. No warm tint. Interactions use weight, translation, and color fade — not color pops.

### Motion
Three-layer system. Purposeful, not decorative. Always respects `prefers-reduced-motion`.

1. **Signature / first-paint** — `Loader` component (client): hairline draws across the bottom of the viewport, name + accent dot fade in top-left, then the whole overlay fades out. ~1.4s total. One orchestrated moment. Skipped entirely under reduced-motion.
2. **Route transitions** — `app/template.tsx` + `.page-enter` CSS keyframe: every new page mounts with opacity + 10px fade-up over 600ms, `cubic-bezier(0.16, 1, 0.3, 1)`.
3. **Scroll reveals** — `<Reveal>` component wrapping major sections + card children. IntersectionObserver triggers opacity + 16px fade-up over 800ms. Stagger delay passed as a prop (80ms between work/pixels card siblings). Under reduced-motion, content appears instantly with no transform.

**Hover micro-interactions** (unchanged):
- `.row-link` — title color-fades, arrow translates +4px on hover
- Work card thumbnails — video autoplays on mount, image scales 1.02 on hover
- `HoverPill` — accent-colored cursor follower over Work thumbnails
- Case study side-nav — scroll-spy active indicator fades in/out 300ms

**Easing vocabulary:**
- `cubic-bezier(0.16, 1, 0.3, 1)` — ease-out-expo equivalent, confident deceleration (most entrances)
- `cubic-bezier(0.19, 1, 0.22, 1)` — slightly snappier (row-link arrow)
- No bounce / elastic anywhere. No animated layout properties — transform + opacity only.

**Smooth scroll** — html `scroll-behavior: smooth`, disabled under reduced-motion.

### Accessibility
- Focus-visible ring (cool, not blue) on all interactive elements
- Case study side-nav has proper aria-label and anchor links (keyboard navigable)
- Body copy max-width 58–62ch
- No text-on-image; all text on solid background for contrast

### Scope — what's explicitly NOT on this site
- Pre-Pineapple roles / work history timeline / education (per Vishal)
- Metrics-first case study framing (craft-positioned, not dashboard-positioned)
- Display serif / italic emphasis
- Card grids with thumbnails on index pages
- Popover / floating nav — simple text nav in the page header
- Warm amber tint / accent color
- Page-load motion choreography
